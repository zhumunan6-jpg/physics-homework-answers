# 物理作业答案

一个适合 iPhone 的静态作业查询工具。输入作业次数与题号（例如 `11 3`）即可定位原页。

- 正式作业：第 11～18 次；补充练习不编入索引。
- 保留原页版式，支持跨页阅读、放大、页码跳转。
- Safari 分享菜单中选择“添加到主屏幕”，即可作为独立窗口的网页应用使用。
- 已访问原页可通过浏览器缓存离线重看；缓存是否保留由系统决定。
- 无登录、统计脚本、外部字体或第三方前端依赖；最后查题位置仅存于本机。

## 原文编号异常

- 第 12 次：未找到第 18 题（第 17 题后直接为第 19 题）。
- 第 13 次：两道题均标为第 23 题，没有标出第 24 题。搜索 23 时按内容二选一。
- 第 13 次第 22 题以图片保存，已人工补入定位。
- 第 18 次带星号的第 24 题是正式作业，已收录。

网页仅包含原 PDF 第 5～82 页的渲染图像，不包含封面、前言、概念思考、原 PDF 文件或其隐藏元数据。未修改、校正原文答案。

## 本地运行

用任意静态服务器提供 `docs/` 目录。例如 `python -m http.server 8000 --directory docs`。
GitHub Pages 发布源为 `main` 分支的 `/docs`。
